# Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Broaden actual product discovery and make selected-product monitoring efficient and trustworthy.

**Architecture:** Extend the existing adapter/SQLite application. Keep reference-only data separate from retail delivered prices, and keep independent schedules per source.

**Tech Stack:** Python 3.11+, FastAPI, SQLite, plain JS.

**Spec:** `docs/superpowers/specs/2026-11-08-phase2-design.md`.

## Global Constraints

- Integer EUR cents; unknown shipping is unknown.
- No paid services, access bypasses, secret disclosure or automatic merge.
- Workers use isolated branches/worktrees; parent integrates and tests.
- User expressly requested autonomous execution; routine choices do not wait for approval.

## Review Focus

- Legacy watches must retain their old effective cadence after upgrade.
- Black-Week exit and mixed source limits must not strand or accelerate failed sources.
- A cache hit must not become a fictitious new price observation.
- Similar names, conflicting packs/variants, and different sellers must not silently share history.
- Reference-only prices or unknown shipping must not produce purchase alarms.
